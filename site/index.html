glyphcast

Видео цветными символами: плеер на WebGL2 и поток символов вместо видео

GitHub npm

YouTube идёт через локальный сервер: браузер не даёт читать кадры чужих видео. Запустите npx glyphcast serve (нужны ffmpeg и yt-dlp), и сервер будет присылать сразу символьный поток со звуком.
